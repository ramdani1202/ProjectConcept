# Project Concept

Aplikasi untuk memetakan konsep sebuah project lewat canvas visual — taruh catatan atau gambar sebagai node, lalu hubungkan satu sama lain untuk menunjukkan alur kerja, mirip seperti n8n. Bisa diinstal langsung dari Chrome ke layar utama HP, dan berjalan offline.

## Cara install ke HP

1. Buka link situs Project Concept di Chrome (Android) atau Safari (iPhone).
2. **Android (Chrome):** ketuk menu titik tiga di pojok kanan atas → pilih **"Tambahkan ke layar utama"** atau **"Instal aplikasi"**.
3. **iPhone (Safari):** ketuk ikon share (kotak dengan panah ke atas) → pilih **"Tambah ke Layar Utama"**.
4. Ikon Project Concept akan muncul di layar utama seperti aplikasi biasa.

## Membuat project baru

1. Di halaman utama (daftar project), ketuk tombol **+** oranye di pojok kanan bawah.
2. Project baru langsung terbuka dengan nama default "Project baru".
3. Ketuk judul di bagian atas untuk mengganti nama project sesuai konsep yang mau kamu buat.

## Menambah node (kotak catatan/gambar)

Di bagian bawah layar canvas ada tiga tombol:

- **+ Teks** — menambahkan kotak catatan kosong. Ketuk kotaknya lalu langsung ketik isi catatan.
- **+ Gambar** — membuka galeri untuk memilih gambar. Setelah dipilih, gambar otomatis muncul sebagai node baru di canvas (ukuran gambar menyesuaikan otomatis, dan otomatis dikompres biar ringan).
- **Export PDF** — menyimpan seluruh isi canvas (semua node + garis koneksi) menjadi satu file PDF yang bisa dibagikan.

## Mengatur posisi node

- **Geser node** — sentuh dan tahan badan node (bukan di titik lingkaran atau area teks), lalu geser ke posisi yang diinginkan.
- **Edit teks** — ketuk langsung area teks di dalam node untuk mengetik/mengubah catatan.
- **Hapus satu node** — ketuk node untuk memilihnya (muncul tanda ✕ merah di pojok node), lalu ketuk tanda ✕ tersebut.

## Menghubungkan node (membuat alur)

1. Setiap node punya dua **titik lingkaran kecil**: satu di sisi kiri (titik masuk) dan satu di sisi kanan (titik keluar).
2. Sentuh titik lingkaran di sisi **kanan** node pertama, lalu geser jari ke titik lingkaran di sisi **kiri** node kedua, lalu lepas.
3. Garis panah oranye akan muncul menghubungkan kedua node, menunjukkan arah alur.
4. **Menghapus koneksi** — ketuk garis penghubungnya, akan muncul konfirmasi hapus.

## Melihat seluruh canvas

- **Zoom in/out** — gunakan tombol **+** dan **−** di pojok kiri bawah, atau cubit layar dengan dua jari (pinch-to-zoom).
- **Kembali ke ukuran normal** — ketuk tombol **1:1**.
- **Geser pandangan (pan)** — sentuh area kosong di canvas (bukan node) lalu geser.

## Membatalkan kesalahan (Undo)

Kalau salah menaruh, menggeser, menghapus node, atau salah menyambung koneksi, ketuk tombol **↶ (panah melengkung)** di pojok kiri atas layar canvas. Setiap ketuk akan mengembalikan satu langkah terakhir.

## Menyimpan project

- Project **tersimpan otomatis** setiap kali ada perubahan (ditandai teks "Menyimpan…" lalu "Tersimpan" di pojok kanan atas).
- Kamu juga bisa mengetuk tulisan **"Tersimpan"** itu untuk memicu simpan manual kapan saja.
- Semua data tersimpan di penyimpanan lokal HP/browser kamu — **tidak akan hilang saat aplikasi ditutup atau HP di-refresh**, kecuali kamu sendiri yang menghapusnya.

## Mengelola daftar project

- Kembali ke daftar project dengan tombol **panah kembali (‹)** di pojok kiri atas layar canvas.
- Setiap project ditampilkan sebagai kartu, lengkap dengan jumlah node dan tanggal terakhir diedit.
- **Menghapus project** — ketuk ikon ✕ di pojok kanan atas kartu project, lalu konfirmasi. Tindakan ini permanen dan tidak bisa dibatalkan.

## Export ke PDF

Ketuk tombol **Export PDF** di toolbar bawah saat berada di dalam sebuah project. File PDF akan otomatis terunduh, berisi seluruh node dan garis koneksi persis seperti tampilan di canvas — cocok untuk dibagikan atau dicetak sebagai dokumentasi konsep.

## Catatan penting

- Aplikasi ini bekerja **sepenuhnya offline** setelah pertama kali dibuka — cocok dipakai kapan saja tanpa koneksi internet.
- Data disimpan **per perangkat**. Kalau kamu ganti HP atau browser, data tidak otomatis ikut pindah (belum ada fitur sinkronisasi/cloud).
- Gambar yang diupload otomatis dikompres untuk menghemat ruang penyimpanan, jadi kualitasnya sedikit diturunkan dari file aslinya.
